### RMD-604 — Lifecycle-aware state holder and off-main execution

Current production code uses lifecycle-owned state holders rather than generated bindings directly in composables:

- `MainActivity` owns durable app state (`libraryState`, `downloadsState`, `settingsSnapshot`) as Compose-observed state and starts/stops repository refresh in `onStart`/`onStop`.
- `AppStateRefresher` is a lifecycle-controlled state bridge for blocking core repository calls; it uses a single background scheduler, prevents overlapping refreshes with `refreshInFlight`, and stops idempotently.

## RMD-900 — Unified Media3 playback

Current production playback uses one service-owned Media3 session/player and a controller-only Compose UI:

- `PlaybackSessionService` creates the canonical `ExoPlayer`, configures audio focus and noisy handling, wraps it in one `MediaSession`, and releases both session and player in service teardown.
- `PlaybackScreen.PortraitPlayerScreen` obtains a `MediaController` from the service `SessionToken`, never constructs an independent production player, and sends play/pause/seek/speed operations through the controller.
- `LocalPlaybackPolicy.mediaItemFor(asset)` creates local-only file URI `MediaItem`s and attaches local subtitle configurations.
- `SplitAudioMediaSourceFactory` and `LocalPlaybackPolicy.mediaSourceFor(...)` merge split local video/audio assets with `MergingMediaSource` while keeping completed playback local-only.
- Subtitle and audio selection controls are populated from actual persisted local tracks and update Media3 `trackSelectionParameters`; audio selection is disabled when only one or zero tracks exist.
- `GeneratedUniffiPlaybackPositionGateway` is used from the playback screen to persist playback position at bounded cadence and reset near-complete playback to start according to `LocalPlaybackPolicy`.
- `PlaybackSessionBehaviorInstrumentedTest.independentControllersObserveAndManipulateTheSameServiceOwnedPlayer` proves two independent MediaControllers manipulate and observe the same service-owned session player.
- `LocalPlaybackPolicyTest` covers split A/V planning, local-only URI rejection, subtitle/audio track presentation, position cadence/reset behavior, and audio-selection enablement.
- `MediaSessionBehaviorQualificationTest` guards the service/session and Compose-controller wiring at the JVM level.
